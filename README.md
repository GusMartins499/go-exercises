# Go Exercises

[Português](#português) | [English](#english)

## Português

Exercícios práticos para aprender os fundamentos de Go.

### Tópicos

- `if-else-exercises` — condicionais com `if` / `else`
- `switch-exercises` — `switch`
- `loop-exercises` — laços com `for`
- `maps-exercises` — maps
- `packages-exercises` — pacotes

Cada tópico tem 5 exercícios (`exercise-1` a `exercise-5`), com o enunciado em comentário no topo do `main.go`.

### Como rodar

Requer Go 1.26+.

```sh
cd loop-exercises
go run ./exercise-1
```

## English

Hands-on exercises for learning Go fundamentals.

### Topics

- `if-else-exercises` — `if` / `else` conditionals
- `switch-exercises` — `switch`
- `loop-exercises` — `for` loops
- `maps-exercises` — maps
- `packages-exercises` — packages
